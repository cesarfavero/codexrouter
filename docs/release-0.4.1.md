# CodexRouter 0.4.1

This patch release updates the packaged app and macOS menu-bar item to use the CodexRouter branded icon consistently. It also keeps the multilingual documentation, model selection, reasoning-effort settings and GitHub update notification from 0.4.0.

The macOS artifact is built for Apple Silicon. It is unsigned when Apple Developer ID credentials are unavailable; macOS may require opening it via Privacy & Security on first launch.
