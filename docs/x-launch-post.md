Meet CodexRouter 🚀

Use multiple isolated ChatGPT accounts with Codex through one local gateway. Pick your native Codex model, set the default reasoning effort, and let CodexRouter fail over when an account reaches its limit.

✅ macOS desktop app
✅ Local-only credentials
✅ Automatic usage-aware account failover
