# CodexRouter desktop app

## Intent
A warm, clear operations console for managing Codex accounts, routing, usage, and Jev policy.

## Visual direction
Park Atlas Desk: warm paper canvas, pine green structure, ochre and terracotta accents, teal status signals, layered map-like surfaces.

## Layout
Compact left rail with clear active state. Main content uses a flexible operational canvas with a lead status field, compact summary metrics, and dense but breathable tables/forms.

## Components
Shared warm panel, compact field, status chip, native-like custom select with an inset chevron, navigation item, and section header. Avoid browser-default borders and edge-hugging arrows.

## Color and type
Warm stock #f4eddd; pine #315d4b; terracotta #c7773e; teal #347b7d; charcoal #28322d. Use existing app typography with stronger hierarchy and generous line-height.

## Interaction
Preserve existing semantic controls and keyboard behavior. Jev is a first-class navigation destination. Loading, empty, and error states retain the same layout.

## Finish line
No black browser-default borders, no clipped controls, no native select arrows at the edge, aligned nav/content rails, and a coherent warm palette across overview, accounts, setup, activity, settings, and Jev.
